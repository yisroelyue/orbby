欢迎页空态升级设计稿 · 时间问候 + 示例任务卡 + 技能橱窗 + 会话续接 · 点击卡片与技能可直接体验填入行为

01 / 信息架构与数据源

四模块各有来源：时间问候 = 本地时间（menuWindowShown 信号唤出时刷新）；任务卡 = 静态配置三条，点击只填入输入框并聚焦、不自动发送，第三张填「/」由输入框监听自动弹出命令面板；技能橱窗 = SkillService 扫描 ~/.orbby/skills（skills.changed 热更新），点击填「@技能名␣」——尾随空格即面板确认语义；续接 = ChatStorageService 最近会话，点击载入当前 tab（/session 语义）。空即藏：无技能或无历史时整节收起，首跑只剩问候 + 任务卡（右上角可切换预览）。

02 / 窄窗自适应与落地位置

menu 窗宽 = 屏宽 1/3，实际落在约 455–853px：任务卡 3 列 → 窄窗 Wrap 降两列/一列，技能 chip 自然换行，节头不省略。Flutter 落点在 _buildChatBody 的 Expanded 空态分支内部（替换现 _AgentHints），不触碰主 Column 的 children 结构；本稿无新增色值，全部映射既有 token（raised / line / ink / ink3 / accentDeep / hover / lineSoft）。

03 / 时间问候档位

主标题按本地时间取五档，副标题固定品牌句「让想法成为现实 —— 从一句话开始」；两板分别演示早/晚档。

05 – 11早上好。今天从哪件事开始？
11 – 14中午好。趁间隙理清一件事。
14 – 18下午好。继续推进手头的事。
18 – 23晚上好。想捣鼓点什么？
23 – 05夜深了。安静的时刻适合想清楚事情。
