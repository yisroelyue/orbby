尺寸与间距

640 × 1000窗口逻辑尺寸（屏宽 1/3 × 可见屏高），最小高 200 不变
18px窗口圆角；面板 / 输入框 14px；卡片 12px；tab 9px；小标签 5px
50px顶部 tab 栏高；tab 本体 32px 高、宽 = 栏宽 1/4（155px）
16px内容区左右内边距；消息上下 7px；正文行高 1.75
24 / 38px正文左缩进 24px（状态点轨 14 + 间距 10）；工具块再退一档到 38px
13.5 / 12.5 / 11.5px消息正文 / 代码与命令 / 工具行与元信息
1px 描边层次全部由描边 + 底色反转表达，不叠阴影；阴影只用于浮层与窗口

层次规则 三层底色 + 三级文字

surface窗口底 = 内容区底，两者同色，靠 tab 栏 hairline 分隔，不做横向分区
raised需要「浮起来」的东西：激活 tab、输入框、命令面板、提问卡片、变更面板、留痕卡
sunken需要「沉下去」的东西：代码块、diff 正文底、提问卡片内的自定义输入框
ink最强：用户消息正文、卡片标题、路径
body次强：Agent 正文、代码正文
ink-2 / ink-3元信息：工具行标题 / 工具参数、问题文案、占位、提示

设计要点 逐条对应现有实现，功能与交互零改动

窗口形态完全保留：无边框、贴屏右上、宽度 = 屏宽 1/3、可拖拽调宽、最小高 200；只把直角换成 18px 圆角并加 1px 描边，浅色由「透明 + 外部投影」改为「暖白面板 + 柔和投影」。

会话 tab 栏由「凸出色块」改为「浮动胶囊」：原 Windows Terminal 式色块依赖「激活 tab 与内容区同色」，浅色体系下同色即失去辨识度，故改为激活 tab 浮起为 raised + 描边，非激活透明融入栏底、hover 浮出浅底；仍为 4 等分、最多 4 个、右端横向滚动。

状态语义全部保留：运行中橙点闪烁、挂起提问红点常亮（后台会话提醒）、用户消息琥珀点 9px、Agent 运行灰点呼吸 / 完成绿点 6px / 终止红点 6px——仅统一色值并都在左侧同一条 14px 轨道上，正文起始位置全窗口对齐。

工具调用去「终端裸文本」化：原本靠 15px 占位对齐的隐藏圆点改为真实的小方点层级标记；工具行标题保持 w600，参数更淡更小，编辑器类仍带子命令（如「编辑器 · str_replace」），折叠组概览文案「正在执行 N 项操作：…」与失败数红字逻辑不变。

文件变更面板与问答留痕卡同构：都从深灰 #202328 块改为 raised 卡片 + 描边，头部一行放「操作标签 + 路径 + 加减行数」；diff 正文沉到 sunken，新增 / 删除行用 13% 透明度的绿红底，等宽字体不变。

问答留痕卡的 header 标签改用主色系：原蓝底标签 #56A8F5 与新的琥珀主色混用会花，标签统一为 accent-soft / accent-deep；「已跳过」降为 ink-3，与已回答形成强弱对比。

命令面板与提问卡片视觉同源：统一为 raised 卡片 + 12px 圆角 + 浮层阴影，行高 34px、左列 /命令名 固定 126px 宽（原 132px），说明右对齐截断；提问卡片选项行 32px、选中态为浅底 + 内描边，多选方框、自定义答案输入框、底部键位提示全部保留。

输入框从「深灰填充块」改为「白卡描边」：raised 底 + 14px 圆角，聚焦时琥珀描边 + 3px 光环；发送按钮改为 30px 琥珀圆钮 + 墨色纸飞机（深色主题同款），位置与原 suffixIcon 一致，仍为单行起、最多 10 行，Enter 发送 / Shift+Enter 换行不变。

回到底部浮钮：由实心深灰圆钮改为描边白卡圆钮，位置、显隐阈值（距底 > 50px 出现）、点击行为不变。

正文字体建议：设计稿正文用系统无衬线、等宽只留给代码 / 参数 / 路径。若想保留原「终端等宽格子感」，把消息正文与输入框换回 Sarasa Mono SC 即可，其余 token 无需改动。

两处新增（可选，需确认）：① tab 栏右端「＋」按钮——只是把已有 /new 命令显式化，达到 4 个上限时同样提示先关闭；② 空态的品牌标识与一行副标题——原标题区为空，如不需要可只留输入框。两处都不改变任何既有逻辑。

文案：输入框占位由英文 Type something or use /help to list commands 改为「输入消息，或使用 /help 查看命令」，其中 /help 与后续命令词统一用琥珀 chip 样式；是否替换由你定。
